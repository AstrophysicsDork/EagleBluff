## Common Misunderstandings (Prevent in Listing)

| Misunderstanding | Prevention |
|------------------|------------|
| Expected resort amenities | Set expectations in listing + welcome book |
| Ran out of groceries | "Before you leave home" section |
| Missed ferry | Dedicated ferry guide + pre-arrival message |
| Septic issues | House rules + quick start + registration ack |
| Cell coverage | Island expectations section |
