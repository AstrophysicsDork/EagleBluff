# Guest Questions Log

> Every time a guest (or prospective guest) asks a question, log it here **before** answering. Patterns here become welcome book content.

**How to use:**

1. Add the question verbatim (or close paraphrase)
2. Note date and source (Airbnb message, phone, in-person, etc.)
3. When answered, add the answer or link to the doc section that now covers it
4. When a question repeats 2+ times, promote it into the appropriate `docs/` file
