## How to Log

| Field | Description |
|-------|-------------|
| **Date** | When issue found or work completed |
| **Category** | Plumbing, electrical, appliance, structural, septic, exterior, other |
| **Description** | What happened or what was done |
| **Cost** | If applicable |
| **Vendor** | Who did the work |
| **Follow-up** | Open items |
